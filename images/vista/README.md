# Windows Vista assets for the personal desktop theme

Original Microsoft Windows Vista assets are stored locally and loaded by the Vista mode of `90s.html`. The rest of the portfolio does not use the wallpaper or cursors. Shell icons are used for their actual meanings: folders for projects, documents for experience, user accounts for the biography, Control Panel for skills, and a computer/network for the desktop.

Source: [bartekl1/windows-ui-assets](https://github.com/bartekl1/windows-ui-assets), extracted from official Windows installations. Microsoft retains ownership of the Windows resources; the archive describes their use as archival, educational, and personal. The archive's MIT license covers its repository structure/documentation, not Microsoft's graphics. This personal portfolio is a nostalgic themed page and is not a Microsoft product or endorsement.

Icons are the original multiresolution ICO files, not recreated illustrations. `start-orb.svg` is the logo viewport of [Windows 2007.svg](https://commons.wikimedia.org/wiki/File:Windows_2007.svg), a CC0 vector rendition by Niral Bhatt (current Commons revision). The rest of the vector illustration is clipped by the viewBox; its paths are unchanged. The profile tile uses Griffin's existing headshot. Glass borders, title bars, control states, and the search field are CSS/HTML so they remain usable at different sizes.
