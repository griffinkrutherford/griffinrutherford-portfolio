# Windows XP desktop assets

The XP variant of `90s.html` uses original Windows XP resources served locally. Microsoft retains ownership of its graphics; this is a personal, nostalgic portfolio theme.

## Windows flag and Luna sprites

Source: [Tiago Costa’s WindowsXP archive](https://github.com/tdcosta100/WindowsXP), which documents extracting sprites directly from the original Luna Blue theme. Files are unchanged; CSS selects the Start-button states from the original sprite sheet.

| Local file | Archive resource |
| --- | --- |
| `windows-logo.png` | `images/System/WindowsLogo-small.png` |
| `start-button.png` | `images/Themes/Blue/StartButton.png` |
| `taskbar.png` | `images/Themes/Blue/TaskbarBackground.png` |
| `taskbar-tray.png` | `images/Themes/Blue/TaskbarTray.png` |

The original XP flag is used in the theme picker, selected-theme button, Start button, and browser favicon. All desktop shell icons, including breadcrumbs and folder status, switch to XP resources and restore their Vista originals when leaving XP. Window borders, controls, menus, and content remain HTML/CSS so the page remains usable at different widths. `../theme-icons/matrix.svg` is an original vector digital-rain badge; Kirby retains its existing Warp Star sprite and Vista its Start orb.
