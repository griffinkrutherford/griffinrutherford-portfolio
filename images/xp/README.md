# Windows XP desktop assets

The XP variant of `90s.html` uses the original Bliss wallpaper and XP shell icons from the same [Windows UI Assets archive](https://github.com/bartekl1/windows-ui-assets) used for Vista. The archive extracts resources from Windows installations; Microsoft retains ownership of its graphics. These files support this personal, nostalgic portfolio theme.

| Local file | Original resource |
| --- | --- |
| `bliss.jpg` | `Wallpapers/Windows XP/Desktop/Bliss.bmp`, converted to JPEG at quality 88 for web delivery |
| `computer.ico` | `Icons/Windows XP/ico/shell32.dll/ICON16_1.ico` |
| `network.ico` | `Icons/Windows XP/ico/shell32.dll/ICON18_1.ico` |
| `folder.ico` | `Icons/Windows XP/ico/shell32.dll/ICON4_1.ico` |

The four-panel XP-inspired mark and Matrix terminal icon in `../theme-icons/` are original SVG drawings. Vista uses its existing Start orb; Kirby uses the existing Super Star Warp Star sprite. Window borders, Start menu, taskbar, buttons, and dropdown are HTML/CSS with working controls.
