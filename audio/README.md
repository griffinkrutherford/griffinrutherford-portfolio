# 90s page sound effects

The Nintendo variant uses five original *Kirby Super Star* (SNES) effects in
`kirby-super-star/`: `ability-gain.wav`, `menu-select.wav`, `star-bounce.wav`,
`1up.wav`, and `pop.wav`. The ability picker plays `ability-gain.wav` when the
selected ability changes.

Source: [The Sounds Resource's Kirby Super Star sound-effects archive](https://sounds.spriters-resource.com/snes/kirbysuperstar/asset/412899/), submitted by Hypernova. The archive was retrieved from a [Wayback Machine capture](https://web.archive.org/web/20251103032603/https://sounds.spriters-resource.com/snes/kirbysuperstar/asset/412899/) because the live download was unavailable.

The old AOL dial-up sample and playback have been removed from the 90s page.
