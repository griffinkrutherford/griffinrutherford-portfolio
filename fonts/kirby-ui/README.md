# Kirby page pixel fonts

The Nintendo version of `90s.html` uses [Pixelify Sans](https://github.com/google/fonts/tree/main/ofl/pixelifysans) for dialogue and [Press Start 2P](https://github.com/google/fonts/tree/main/ofl/pressstart2p) for short menu labels. Both are bundled locally under their respective SIL Open Font Licenses, included here as `OFL-PixelifySans.txt` and `OFL-PressStart2P.txt`.

These are era-inspired substitutes, not fonts extracted from *Kirby Super Star*. [The game's font sprite sheet](https://www.spriters-resource.com/snes/kirbysuperstar/asset/2892/page-1/) is available as an image; a [playable recreation](https://fontstruct.com/fontstructions/show/2466905/kirby-super-star-dialogue) exists but is not available for download or reuse.
